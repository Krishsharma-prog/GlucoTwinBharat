# Upload the GlucoTwin Bharat walkthrough

1. Download `GlucoTwinBharat_Demo_Walkthrough.mp4`.
2. Open YouTube Studio → Create → Upload videos.
3. Upload the MP4. Suggested title: **GlucoTwin Bharat | Digital Twin Challenge 2026 | Prototype Walkthrough**.
4. Set Visibility to **Unlisted** (not Private), unless the challenge portal explicitly asks for a different setting.
5. Add `GlucoTwinBharat_Subtitles_Synced.srt` under Subtitles → Upload file → With timing.
6. After processing, open the link in an incognito window to confirm that evaluators can view it.
7. Copy the share URL into the `Demo Video` section of `README.md` in the public GitHub repository, then confirm the README link is publicly accessible.

**Important scope note:** This generated video is a narrated project walkthrough using the project's presentation and data-backed dashboard illustrations. It is not a continuous screen recording of the actual React frontend. If the challenge evaluator expects a live application screen recording, record the running React app and replace/augment this video before final submission. The narration uses a synthetic voice. All patient and prediction examples are synthetic and are not clinical evidence.
